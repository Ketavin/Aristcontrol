# Arist AI Control 1.0.3

This update fixes the observed `Claude` to `cloud` voice-recognition error.

## Claude correction

- A standalone recognized `cloud` utterance is corrected to `Claude`.
- `cloud code`, `cloud fable`, `cloud opus`, `cloud sonnet` and `cloud haiku` are corrected to their canonical Claude names.
- Longer dictation is corrected only when a strong model or coding context is present.
- Ordinary phrases such as `cloud service`, `cloud storage`, `AI cloud service` and `Cloudflare Workers` remain unchanged.

## Upgrade

1. Download `Arist-AI-Control-v1.0.3-Windows-x64.zip` and its `.sha256` file.
2. Verify the ZIP hash and extract the complete archive.
3. Run `Install.cmd` as the same normal Windows user.

The installer preserves the current user's API Key, terminology, correction rules and BLE pairing configuration.
