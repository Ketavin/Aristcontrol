# Arist AI Control 1.0.2

This update improves voice recognition of current AI model and product names.

## Model vocabulary

- Claude Fable 5, Claude Opus 5, Claude Sonnet 5 and common Claude family names.
- GPT-5.6 Sol, Terra and Luna, GPT-5.5 and GPT-5.3-Codex.
- Gemini 3.6 Flash, Gemini 3.5 Flash, Gemini 3.1 Pro and Nano Banana 2.
- DeepSeek-V4-Pro, DeepSeek-V4-Flash, Qwen3.7-Plus, Qwen3-Coder-Next, GLM-5.1, Kimi K3 and MiniMax M2.5.

The ASR glossary receives the canonical names directly. High-confidence correction is limited to complete model phrases, so ambiguous ordinary words such as `cloud` are not automatically rewritten as `Claude`.

## Upgrade

1. Download `Arist-AI-Control-v1.0.2-Windows-x64.zip` and its `.sha256` file.
2. Verify the ZIP hash and extract the complete archive.
3. Run `Install.cmd` as the same normal Windows user.

The installer preserves the current user's API Key, custom terminology, correction rules and BLE pairing configuration.
