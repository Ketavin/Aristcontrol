# Arist AI Control 1.0.1

This is the recommended in-place laptop upgrade from Arist AI Control 1.0.0.

## What is included

- Natural punctuation derived from real speech prosody and pauses.
- Conservative local WeChat chat polishing with at most one cue-backed final emoji.
- Runtime protection and ASR priority for user-defined terminology and names.
- Verified official sherpa-onnx Java dependency bootstrap for reproducible builds.

## Upgrade

1. Download `Arist-AI-Control-v1.0.1-Windows-x64.zip` and its `.sha256` file.
2. Verify the ZIP hash, then extract the complete archive.
3. Close Arist AI Control and run `Install.cmd` as the same normal Windows user.
4. The installer backs up the old application directory and starts 1.0.1 automatically.

The upgrade preserves the current user's DPAPI-protected DashScope API Key, terminology, correction rules and BLE pairing configuration. Personal names are not bundled in the public archive; names already stored in `%LOCALAPPDATA%\AristAIControl\terminology.txt` remain in place.

## Verification

- Clean Windows Java 17/Maven build.
- Offline transcript normalization, chat-polish safety and terminology-priority smoke tests.
- Package version, private-data exclusion and SHA-256 sidecar verification.
