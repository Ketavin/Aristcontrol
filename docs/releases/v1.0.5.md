# Arist AI Control 1.0.5

This update improves Windows stability, removes more redundant WORK dictation and expands development terminology.

## Stability

- Ordinary minimize and RDP desktop transitions no longer automatically hide the app to the tray.
- Production text injection no longer keeps a delayed OLE clipboard lease that could terminate the process inside Windows `ole32.dll` when applications switch.
- The existing target-window and session commit guards remain active for Unicode injection.

## Text polishing

- WORK mode safely collapses clear stutters, repeated development nouns and exact duplicate clauses.
- Ordinary clauses stay together long enough for the model to remove restart phrases and semantic repetition.
- CHAT mode retains its conservative, tone-preserving behavior.
- The UI now distinguishes full polish, partial fallback and rule-only fallback.
- One transient connection failure is retried before falling back to deterministic cleanup.

## Terminology

- Adds `P0`, `P1`, `DSH`, `DeepSeek Harness` and canonical `Arist` forms.
- Adds `远端 GitHub`, `remote GitHub` and `GitHub remote`.
- Corrects the observed `远端 GitLab` ASR error only in that exact remote-GitHub context; standalone `GitLab` remains unchanged.

## Upgrade

1. Download `Arist-AI-Control-v1.0.5-Windows-x64.zip` and its `.sha256` file.
2. Verify the ZIP hash and extract the complete archive.
3. Run `Install.cmd` as the same normal Windows user.

The installer preserves the current user's API Key, terminology, correction rules and BLE pairing configuration.

- Offline terminology, text-polish, transcript-normalization and injection-policy smoke tests.
- Packaged Java runtime, BLE bridge, installer and embedded terminology verification.
- Installed-app startup and user-dictionary merge verification on Windows.
