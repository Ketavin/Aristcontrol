# Arist AI Control 1.0.0

The first public Windows release of Arist AI Control.

## Highlights

- Bluetooth controller connection, reconnect and state synchronization.
- Four-key × three-mode configuration, OLED upload and light-state feedback.
- Codex hook integration with a physical manual/automatic approval boundary.
- Qwen-powered voice dictation with terminology bias, high-confidence correction and focus-guarded injection.
- Natural WeChat chat mode with prosody-aware punctuation and a conservative, cue-backed optional final emoji.
- Versioned, self-contained Windows x64 package with Java 17, BLE bridge, installer, preflight checks and remote voice test guide.

## Install

1. Download `Arist-AI-Control-v1.0.0-Windows-x64.zip`.
2. Verify it against the attached `.sha256` file.
3. Extract the complete ZIP.
4. Run `Install.cmd` as a normal Windows user.
5. Enter a Bailian DashScope API Key when prompted on first install.

Personal names are intentionally not bundled. Add custom names and terminology to `%LOCALAPPDATA%\AristAIControl\terminology.txt`, one entry per line.
